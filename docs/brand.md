# NetCat 品牌规范

## 品牌定义

- 英文名：NetCat
- 中文名：奈特猫
- 标语：本地守候每一次请求
- 作者：kaite han
- 定位：面向开发者的本地 HTTP/HTTPS 抓包与 Mock 工具
- 品牌气质：专业、敏捷、本地优先；猫的意象只用于表达守候和敏锐，不使用过度拟人化文案。

## 功能简介

NetCat（奈特猫）是一款面向开发者的本地 HTTP/HTTPS 抓包与 Mock 工具，可查看请求与响应、筛选流量、重放请求、构造 Mock，并管理本地 CA 与系统代理。流量、规则与设置默认只保存在本机。

## 命名规则

- 安装包、窗口标题和主品牌统一使用 `NetCat`。
- 主界面副标题使用 `奈特猫 · LOCAL PROXY`。
- 技术标识使用小写 `netcat`，bundle identifier 使用 `com.kaitehan.netcat`。
- 用户可见文案不绑定单一操作系统，以便未来扩展 Windows 版本。
