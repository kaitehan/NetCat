# NetCat 0.6.2 智奈稳定性验收

## 修复范围

- DSH 错误轮次不再保存为空白助手回复或显示为“已完成”。
- 缺少 API Key 时显示凭据缺失状态，并允许用户修正后重试。
- 等待模型期间展示公开生命周期摘要，不保存或展示模型隐藏推理。
- OpenAI 兼容服务的 HTTP 错误读取受限大小的 JSON 原因，完成凭据脱敏并显示操作建议。
- NetCat、Harness Bridge、插件和内置 Runtime 版本统一为 `0.6.2`。

## 安全约束

- API Key 不写入错误消息、SQLite、日志、Bridge 事件或验收文件。
- 仅展示 DSH 公开生命周期阶段和工具活动，不展示模型隐藏推理内容。
- HTTP 错误正文最多读取 1 MiB；只提取 JSON `error.message` 或 `message`，并限制为 300 字符。
