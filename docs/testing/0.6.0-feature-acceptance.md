# NetCat 0.6.0 智奈 DSH 功能验收

## 验收范围

本记录覆盖 NetCat 0.6.0 的首版智奈集成。本次按要求仅执行本地验证，不检查或等待 CI/CD 流水线。

固定依赖：DSH/SDK/CLI `0.2.3-alpha.2`、Node.js `24.22.3`、DeepSeek `deepseek-official/deepseek-v4-flash`、OpenAI `openai/gpt-4.1`。

## 功能与安全验收

| 能力 | 结果 | 证据或限制 |
| --- | --- | --- |
| 离线 cURL 解析 | 通过 | 不调用 shell；原始请求仅保存在 Rust 内存，投影递归脱敏 |
| 抓包诊断 | 通过 | 只向模型提供白名单字段，敏感 Header 与 JSON 字段脱敏 |
| Mock/QuickJS 草稿 | 通过 | Rust 校验后返回待确认草稿；确认保存时强制保持停用 |
| 一次性联网诊断 | 通过 | 五分钟、单次消费，绑定方法、URL 指纹与 Body 哈希；TLS 校验开启，禁止自动重定向，响应限长 |
| 会话恢复 | 通过 | SQLite schema 7 保存 UI 投影；Runtime 首次使用 Session 时先恢复，失败后创建 |
| Provider 与凭据 | 通过 | DeepSeek/OpenAI 分离安全存储；OpenAI 兼容供应商、模型、Base URL 与 Responses/Chat Completions 协议可配置；UI 不回填 Key；Runtime 通过私有 IPC 读取 |
| OpenAI 连接测试 | 通过 | 用户显式点击后读取当前供应商隔离的安全存储凭据，按所选协议向 `/responses` 或 `/chat/completions` 发起最小请求；禁止重定向且响应限制为 1 MiB |
| 进程回收 | 通过（macOS） | Supervisor 独占 Runtime；停止会终止进程组并清除内存请求 |
| 迟到事件 | 通过 | 仅当前 request/conversation/session/operation 四元组可写投影和发布事件 |
| 敏感数据落盘 | 通过 | 自动化断言原始 Authorization、Cookie、Token、密码不进入 SQLite 投影与工具输出 |

## 发布前人工检查

- 当前本地 DMG 使用 hardened runtime 的 ad-hoc 签名并通过 `codesign --verify --deep --strict`；正式分发需注入 Developer ID 签名身份并完成 Apple notarization。
- 已在 1440px、820px 和 560px 浏览器视口检查智奈会话与设置页，无重叠、溢出或控制台错误；联网、Mock 与脚本草稿状态由组件测试覆盖。
- 使用发布环境测试 Key 分别执行一次 DeepSeek/OpenAI 冒烟，不将 Key 写入日志或验收附件。
- 在 Windows x64 发布机完成 NSIS 安装、升级、冷启动、Named Pipe ACL、DPAPI 和进程树回收验证。
- 对跨域重定向保持不跟随，并由用户为新目标重新发起确认。
