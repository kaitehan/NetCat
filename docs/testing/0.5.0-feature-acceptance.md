## SSL Pinning / Frida

Android 分别准备 Conscrypt/TrustManager、OkHttp、WebView 测试端点；iOS 分别准备 Security/NSURLSession、AFNetworking、Alamofire、TrustKit。每个栈至少验证一次原始失败、注入后成功和会话停止后恢复原行为。

| ID | 步骤与预期 | 结果 | 执行人 / 日期 | 证据 |
| --- | --- | --- | --- | --- |

| P2 | USB 设备、应用和进程枚举正确；设备断开后错误可恢复 |  |  |  |
| P3 | Android 三类栈分别执行 Spawn、Attach；日志和会话状态正确 |  |  |  |
| P4 | iOS 五类栈分别执行 Spawn、Attach；日志和会话状态正确 |  |  |  |
| P5 | Android 与 iOS Gadget 地址连接、注入与停止正确 |  |  |  |
