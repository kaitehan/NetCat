# NetCat 0.6.5 智奈 Runtime 插件打包修复验收

## 修复范围

- 将 NetCat、Harness Bridge、插件和内置 Runtime 版本统一升级为 `0.6.5`。
- 内置 Runtime 在 npm 安装后将 `@netcat/dsh-plugin` 从本地包符号链接物化为普通目录。
- 防止 Tauri 打包应用资源时遗漏符号链接，导致安装版 DSH 无法加载 NetCat 凭据 Provider。

## 根因证据

- 设置页凭据验证和模型直连成功，证明 Keychain 与远端模型配置可用。
- 真实私有 IPC 对 `OPENAI_API_KEY` 返回 `configured: true`，且凭据值非空。
- `0.6.4` 源码 Runtime 的 `node_modules/@netcat/dsh-plugin` 是符号链接。
- `0.6.4` 安装应用中保留了插件源目录，但该 `node_modules` 链接不存在，DSH 因此没有挂载 NetCat credentials 服务。
