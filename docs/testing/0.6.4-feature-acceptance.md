# NetCat 0.6.4 智奈凭据插件验收

## 修复范围

- 修复内置 DSH 无法解析 `@netcat/dsh-plugin`，导致智奈聊天错误报告 API Key 未配置的问题。
- Runtime 构建时将 NetCat 插件登记为 DSH 安装范围依赖，Profile 中的凭据和领域工具插件可正常激活。
- 新增真实 DSH、私有 IPC 和本地 OpenAI 兼容服务集成测试，验证聊天 Turn 会读取 `OPENAI_API_KEY`。
- NetCat、Harness Bridge、插件和内置 Runtime 版本统一为 `0.6.4`。

## 安全约束

- 集成测试只使用临时测试凭据和本地固定 HTTP 服务，不读取或输出真实 API Key。
- API Key 仍只通过一次性认证的私有 IPC 从系统安全存储解析，不写入 Profile、SQLite、日志或 DSH Session。
